## ⚡ Overview

**SYSTEM//PURGE** is a browser-based 3D first-person shooter powered by **Three.js** and procedural Web Audio.
Infiltrate an infected system partition, scan unclassified payloads, match your tactical protocols to hostiles, and defeat **The Hoarder** core boss!

- 🕹️ **Zero dependencies / Single-file design**: Built with vanilla HTML5, WebGL (Three.js), and procedural Web Audio synthesis.
- 📁 **Read-only local folder support**: Play against simulated system clutter or load any local directory in safe read-only preview mode.
- 📋 **Simulated Operation Queue**: Defeating enemies logs recommended cleanup operations (Delete duplicates, Sort files, Archive old archives) that can be inspected and exported as a JSON report.

## 🕹️ Controls

- **WASD**: Movement
- **Mouse**: Aim (Click to lock cursor; drag to look if cursor lock is unavailable)
- **Left Click**: Fire Protocol
- **1, 2, 3, 4**: Switch Protocols
- **Shift**: Sprint
- **Space**: Evasive Dash
- **Q**: Chain Purge (Ultimate ability when charged)
- **Tab / Review Button**: Inspect simulated operation queue
- **Esc**: Pause / Menu
